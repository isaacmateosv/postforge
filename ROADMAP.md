# Roadmap

## Release 1 — publishing foundation

Native macOS app, Postiz drafts, WhatsApp intake, local captions, connection monitoring,
backups, retention and safe update checks.

## Release 2 (v2.0.0) — Telegram connection

- Bot/chat setup and connection test.
- Optional app-alive pings with persisted schedules, bounded requests and retry backoff.
- Explicit stack health in every ping and useful connection/offline alerts.
- External missed-ping monitoring for power/network loss.
- English and Ecuadorian Spanish setup and status copy.

Telegram credentials, code and background requests are not part of release 1.
