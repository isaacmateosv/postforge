Before you start

PostForge needs these on your Mac. The app checks them for you and tells you what is missing.

  • macOS 13 or later (Apple silicon or Intel)
  • Docker Desktop
  • Ollama with a small model, for captions written on your Mac
  • ffmpeg and Python 3
  • Xcode Command Line Tools (xcode-select --install), needed only to build a migration backup
  • Your private .env file with your credentials. It is never included in the installer.

See SETUP.md in the PostForge folder for the full guide.
